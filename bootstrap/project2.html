Ecommerce Site

For the CSCI 440 Database Systems, I created a full model of a small ecommerce site. This was hosted locally using Ammps and had a database to store user credentials, order history, current carts, and inventory/item information. This project was focused on learning the fundamentals of Database Usage for real applications.

The database for this site had the following tables,

Ordered Items: for tracking which items were ordered by which user.

Orders: For each set of items ordered at a single time for a single user.

PriceHistory: For logging the changes in price made in the database.

Products: List of current products, prices, and stock.

SavedCart: Logs of items current in the carts of individual users.

Users: Usernames, userIds, and hashed passwords of each unique user.
